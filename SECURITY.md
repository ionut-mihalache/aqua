# Security Policy

## Reporting a vulnerability

Please **do not report security vulnerabilities in public issues, pull requests or discussions.**

Because __AQUA__ handles shared memory between processes, issues such as memory corruption, out-of-bounds access, race conditions or overly permissive shared memory objects can have security impact. If you find one:

1. Report it privately through GitHub: open the **Security** tab of the repository and click **Report a vulnerability**.
2. If that option isn't available, contact the maintainer at **ionut.mihalache1506@gmail.com**.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it, ideally a minimal client/service example
- The affected version or commit, OS and compiler
- A suggested fix, if you have one

## What happens next

- You will receive an acknowledgement of your report as soon as possible.
- The issue will be investigated, and you will be kept informed of progress.
- Once a fix is available, the vulnerability will be disclosed publicly. With your permission, you will be credited for the discovery.

Thank you for helping keep __AQUA__ and its users safe.
